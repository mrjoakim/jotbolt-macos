# Jotbolt (legacy update feed)

This repo only serves the update feed for Jotbolt 1.0 to 1.11, which moves them to 1.12.0.

- Current downloads and feed: https://github.com/mrjoakim/jotbolt-releases
- Website: https://joakimostlind.se/jotbolt/

Jotbolt up to and including 1.11.0 was published under GPL-3.0-or-later. From 1.12.0 it is closed source.
